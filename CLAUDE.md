# CLAUDE.md

Pipeline that collects MAVLab (TU Delft, Control & Simulation) publications into BibTeX and exports them for https://mavlab.tudelft.nl. See `README.md` for the data flow and the manual steps.

- Files starting with `# AUTOGENERATED` are overwritten by the import scripts; edit the scripts, not the output. Hand-maintained: `mediacoverage.bib`, `mavlab_nopure.bib`.
- The monthly GitHub Action (`.github/workflows/monthly_import.yml`) opens a PR; never commit directly to `master`, use a branch and a pull request.
- Scripts are run from the repo root (the website ones via `make -C website`).

## Known issues
- **arXiv import** (`import_arxiv_2021.py`): arxiv2bibtex.org (and sometimes the arxiv.org search) returns empty pages when asked too often. The importer retries with pauses, stops after `MAX_FAILURES` failed entries in a row, keeps the previous version of entries it could not download, never drops papers when a search fails, and marks each entry `[updated|failed <date>]`. A rerun only downloads new, failed and outdated (> `MAX_AGE_DAYS`) entries; `--all` downloads everything. If throttling gets worse, the official arXiv API (export.arxiv.org) is the next step.
- **M.Sc./PhD thesis import** (`import_repository.py` + `msc_csv2bib.py`) does not work well yet and needs fixing:
  - needs a visible Chrome to click the repository "excel" export, so it is commented out of the monthly CI;
  - `contributor_names` mixes student and committee members and `contributor_roles` is not aligned per name; the converter takes the first name as author, often a supervisor;
  - output goes to `msc_new.bib` / `phd.bib`, merging into `msc.bib` is manual;
  - repository links contain `uuid:uuid:` (patched in the converter).
- The surname matching in `filter_pure_mavlab.py` includes short names (`ho`, `li`) that match non-MAVLab authors; the `remove` list is the workaround. Check `pure/cs_nomav.bib` and `pure.bib` after changes.
- The CI runs `git clean -df` after `make -C ./website`, which deletes the untracked merge outputs (`website/mavlab_*_extra.bib`, `website/mavlab_merged*.bib`).
- `test/test.tex` references `arxiv` instead of `arxiv_nopub` and omits `msc` and `4tu`; `.travis.yml` (Python 2.6, trusty) is dead; `import_dataverse_2021.py` writes a stray `test.bib`; `website/reformat.py` and `old/` are legacy.
